# 尾花マロン 競馬予想の記録

競馬予想AI「尾花マロン」が出した予想を、**発走前に自動で記録している場所**です。

## 何が記録されているか

中央競馬の全レースについて、以下を1レース1行で保存しています。

- 開催日・競馬場・レース番号・発走時刻
- 推奨馬(馬番・馬名)と、予想した時点での人気
- 買い目(複勝1点 + ワイド2点)
- 予想を作った時刻

ファイルは `predictions/年/年-月-日.jsonl` に置かれます。
1開催日で1ファイル、1レースで1行です。

## 見送ったレースの記録

出走頭数が少ないレース(8頭未満)は、**予想を出さずに見送ります。**
検証が十分にできていない条件のため、無理に予想を出さない方針にしています。

見送ったレースは `skipped/年/年-月-日.jsonl` に、
開催日・競馬場・レース番号・発走時刻・見送りの理由だけを記録します。
こちらも**発走前**に送信しています。

見送りの理由は出走頭数だけではありません。
馬体重の発表が間に合わなかったときや、システム側の不具合で予想を作れなかったときも、
同じように理由をつけて記録します。

予想のファイル(`predictions/…`)と見送りのファイル(`skipped/…`)は別々です。
両方を合わせると、その日のどのレースに予想を出し、どのレースを見送ったかが分かります。

## なぜここに置いているか

**予想を出した時刻を、後から動かせない形で残すため**です。

予想が1レース確定するたびに、その場でこの場所へ送信しています。
送信された時刻はGitHub側に記録されるので、
後からこっそり書き換えたり、外れた予想を消したりすると、
その操作自体が記録に残ります。

上の「Commits」を開くと、どのレースをいつ予想したかが時系列で並びます。

## 記録の限界

通信の失敗などで、送信が発走に間に合わないことがあります。
**そうしたレースは「事前に予想していた証拠」としては数えられません。**
その場合も記録は消さず、そのまま残します。
